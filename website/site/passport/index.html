你手里的 vibe coding 遥控器。

给 FoloToy AI Passport 刷上 InputBetter 固件，它就成了一只带屏幕的三键遥控器：按住说话，文字进入 Mac 的光标处；上键回车、下键 Esc；Claude Code / Codex 完成或等你确认时，它会响铃提醒。

在浏览器里刷入固件 下载 macOS 版

没有这只硬件也没关系：InputBetter 本身完整可用。Passport 只是给喜欢折腾的人多一种输入方式。

  • USB-C 或蓝牙插线即用，无需配对
  • 屏幕提示跟着按键走改了映射，图标同步变
  • 固件开源MIT，为本项目全新编写
  • 上键回车 · 长按切换模式
  • 下键Esc · 长按切换应用
  • OK按住说话

能做什么

三个键，把说话变成操作。

设备只上报按键、显示 Mac 下发的状态；所有含义都由 Mac 上的 InputBetter 决定，所以行为随 app 更新而更新。

01

按住 OK 说话

松开后文字输入到 Mac 的当前光标处；短按一下开始、再按一下结束，可以免提。也可以把 Passport 的麦克风设为听写音源。

02

上键回车，下键 Esc

默认映射：回车发送 prompt，Esc 打断 Agent。可在 设置 › Passport 改成 ⌫ 退格、⌦ Delete、⌘Z 撤销、Tab、⇧Tab、⌘↩、⌃C、确认第一项或再次输入上一段。

03

长按上键切换模式

听写 → 翻译听写 → 字幕，循环切换；屏幕上的点阵图标重排成新模式的图标，模式名翻牌切换。字幕模式下按 OK 开始或停止字幕，上键开关翻译，下键收起字幕条。

04

长按下键切换应用

屏幕上列出 Mac 正在运行的应用，上下键选择、OK 确认，该应用的窗口就前置并聚焦。录音中长按下键则取消本次录音。

05

Agent 完成时响铃

在 设置 › Vibe Coding 一键配置 Claude Code / Codex 的 hooks：任务完成显示 DONE 并响铃，等你确认时显示 YOUR TURN、每 20 秒提醒一次，按任意键关闭。

06

一块点阵屏

整块屏幕只用一种圆点：模式图标、跟着声音跳动的声波、处理中的扫描光、完成状态都由同一批点组成，切换时点会重排。不显示你说的内容；彩色只留给录音、完成和 Agent 提醒。离线时是一只点阵时钟。

在浏览器里刷入固件

插上 USB-C 线，用电脑上的 Chrome 或 Edge 直接刷，无需安装任何工具。也可以在 InputBetter app 的 设置 › Passport 里一键刷入，两边用的是同一份固件。

  1. 长按电源键开机，用支持数据传输的 USB-C 线连接电脑
  2. 先退出 InputBetter app，它会占用串口
  3. 点「连接并刷入」，在弹窗里选择 Passport

网页会先确认芯片是 ESP32-C3、Flash 为 8 MB、分区表里有 Passport 的身份分区，不是 Passport 就停止。
