常见问题

需要哪些系统权限？

两项：麦克风用来听你说话，录音只在按下快捷键时进行；辅助功能用来监听快捷键，并把文字粘贴到当前光标处（听写通过写入剪贴板再模拟 ⌘V 输入，之后会恢复原来的剪贴板内容）。

开启实时字幕、第一次采集某个应用的声音时，macOS 会弹出系统音频录制的授权请求。这个权限没有公开的查询接口，所以 app 不会提前检查它。

如果听写后文字没有出现，多半是辅助功能权限没给，或目标输入框不接受粘贴——这时文字会留在剪贴板里，状态条会显示「已复制」，手动粘贴即可。

模型下载很慢或失败怎么办？

模型从 Hugging Face 下载，一个源失败会自动换到镜像（hf-mirror），全部失败才报错，重试即可；也可以在 设置 › 识别模型 里改为优先使用镜像。

想先用起来：Apple Speech 不用下载；SenseVoice Small 只有约 240 MB，中文极快；默认的 Whisper Large v3 Turbo 压缩版约 650 MB。

第一次加载 Whisper 时，CoreML 要为本机芯片优化模型，约需 2–3 分钟，之后每次加载约 1.6 秒。

Passport 连不上 Mac？

长按电源键开机，用支持数据传输的 USB-C 线连接（不少线只能充电）。USB 连接优先；拔掉线后会自动转到蓝牙，广播名 InputBetter，不需要配对，蓝牙可以在 设置 › Passport 里关闭。

设备上运行的不是 InputBetter 固件时，app 会在 设置 › Passport 提示你刷入。一台 Mac 上同一时间只能有一个程序打开串口，先退出其他串口工具或 Passport 的其他配套 app。

没有连上 Mac 时设备显示时钟，按键只用于点亮屏幕，不会有反应。

刷写固件安全吗？能恢复原来的固件吗？

app 内刷入、网页刷入和命令行脚本三种方式都只写 bootloader、分区表和应用三段，不擦除整片 Flash，也不写设备的身份分区（cardid）。

app 第一次刷某台设备前，会把整片 8 MB Flash 备份到 ~/Library/Application Support/InputBetter/Backups/；网页刷写可以勾选先把备份下载到本机（passport-<MAC>-flash.bin）。备份里含设备身份数据，请妥善保管，不要分享。

网页刷写需要电脑上的 Chrome 或 Edge（Web Serial）；刷之前先退出 InputBetter app，它会占用串口。刷写过程中请不要拔线或关闭页面。

云端识别和 AI 服务会上传什么？

默认所有识别都在本机完成，声音不离开 Mac。只有当你在 设置 › 识别模型 里选择了云端识别模型（火山引擎、阿里云百炼、ElevenLabs、Soniox 或 OpenAI 兼容接口），录音才会发送到对应的服务商。

AI 润色、AI 翻译和字幕总结会把文字发给你自己配置的 AI 服务（任意 OpenAI 兼容接口）；在线机器翻译（DeepL、Google、微软、火山引擎、腾讯云、百度）同理。系统翻译在本机离线完成。

所有 API Key 只保存在本机 ~/Library/Application Support/InputBetter/credentials.json（权限 600），不会上传。字幕记录只在内存里，app 不保存历史。

系统要求与价格？

macOS 26 或更新、Apple 芯片的 Mac。安装包已签名并经 Apple 公证，下载后直接拖进「应用程序」。

InputBetter 和 Passport 固件都以 MIT 协议开源、免费使用。云端识别、在线翻译和 AI 服务由各服务商按量计费，密钥自备。

怎么更新到新版本？

从官网下载的版本每天自动检查一次更新，有新版本时会弹窗说明更新内容；也可以在 设置 › 通用 › 关于与更新 里点「检查更新」，或在菜单栏菜单里选「检查更新…」。

下载新的安装包后打开，把 InputBetter 拖到「应用程序」替换旧版即可，设置和已下载的模型都会保留。自行编译的开源版默认不检查更新，可以按 GitHub 上 README 的说明配置自己的更新接口。
