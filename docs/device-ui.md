# Passport 设备界面设计

屏幕 ST7789 240×320 竖屏,LVGL 9,只显示 ASCII(Montserrat 字体)。**不显示转录内容**,用动画表达状态。

设计原则(固件 0.1.2 起,「点阵」主线):**一屏只突出一件事**,整个界面的主体只用**一种图元——8 px 网格上的 5×5 圆点**。模式图标、录音声波、处理中的扫描光、完成 / 失败、离线时钟、电量,全由同一批点组成;点阵页面之间切换时点"重排"(morph),听写全过程(模式图标 → 一条线 → 声波 → 一条线 → 图标)是一段连续的粒子动画。文字仍用 Montserrat。纯黑底、白 / 灰为主;彩色只留给录音红、完成绿、失败红、Agent 橙、低电量红。

## 配色

| 令牌(固件 `ib_ui_gfx.h`) | 值 | 用途 |
| --- | --- | --- |
| `IB_COLOR_BG` | `#000000` | 背景 |
| `IB_COLOR_SURFACE` | `#181818` | 禁用的按键标记点、列表滚动条轨道 |
| `IB_COLOR_MUTE` | `#303030` | 熄灭的电量点、按键标记点(静止)、处理中的线、禁用的按键图标 |
| `IB_COLOR_RING` | `#505050` | 三级文字(`waiting for Mac`、`press any key`) |
| `IB_COLOR_TEXT_DIM` | `#686868` | 次要文字、按键提示图标(静止)、翻译模式图标 |
| `IB_COLOR_TEXT_MID` | `#A0A0A0` | 状态栏链路文字 |
| `#C8C8C8` | | IDLE 字形的点(扫描光经过时变白) |
| `IB_COLOR_TEXT` | `#F0F0F0` | 主文字、点、选中胶囊 |
| `IB_COLOR_REC` | `#F83858` | 录音:声波活柱、状态栏红点、低电量点 |
| `IB_COLOR_DONE` | `#28E498` | 完成:点短暂变绿、状态字;Agent done |
| `IB_COLOR_ERR` | `#F85858` | 失败的叉;按键"不可用"反馈 |
| `IB_COLOR_AGENT` | `#C88848` | Agent 等待输入 |

**灰色必须是 RGB565 精确值**:R = G = B 且为 8 的倍数(屏幕是 16 位色,R/B 5 位、G 6 位,非精确灰会偏绿)。灰色渐变一律用不透明精确灰(`ib_gray()` / `ib_gray_lerp()`),透明度只用于彩色。

## 点阵网格

- 25 列,列 c 的点心 x = 内容区居中线 − 96 + 8c(c = 12 落在居中线);行 r 的点心(屏幕)y = 28 + 8r;声波 / 线在第 13 行(y 132)。点 5×5、圆角 2。
- 字形(固件 `ib_ui_dots.c`,X = 点):mic(9×10)、translate 两个对话气泡(9×10)、CC 框(9×7)、对勾(11×8)、叉(9×9)、感叹号(3×10)。
- 重排:两个图案各按列优先排序后按序号配对(数量不同时循环复用),每颗点按目标列号错峰 6 ms 起飞,240 ms ease-in-out-cubic 飞到新位置并渐变颜色,飞行中略微放大;整段 ≤ 384 ms。从声波页离开时先用 120 ms 把声波按行塌缩成一条线,再从线重排。
- 主体是点阵的页面(IDLE / REC / PROC / DONE / ERR / SUB)之间"直切":旧页立即隐藏,新页接着上一页的最后一帧让点重排(`ib_ui.c`、`ib_ui_page.h` 的 `prev_screen`)。OFFLINE / LIST / Agent 与它们之间仍是 fade-through(旧页 120 ms 淡出、新页 180 ms 淡入并上移 8 px)。

## 布局

顶部 24 px 状态栏;在线页面右侧 22 px 是按键提示列,页面内容只用左侧 218 px 并在其中水平居中;离线时钟和 Agent 全屏通知使用整屏宽度。所有页面的一行主文字(模式名、状态字、应用名、错误原因)都在 y=220(Montserrat 20)。

### 状态栏

- 左:链路 `USB` / `BLE`(12 px 字距 +1;在线 `#A0A0A0`,离线 `#505050`)。录音时换成脉动红点 + 计时;字幕时换成闪烁白点 + `LIVE`。
- 右:电量是 **5 颗 4 px 圆点**(每颗 20%)。≤20% 且未充电时唯一亮着的点变红;充电时点从左到右循环点亮;**百分比数字只在低电量或充电时出现**。

### OFFLINE(Mac 未连接)

- 点阵时钟:5×7 点阵数字,4 位 + 冒号正好 25 列铺满 200 px;冒号 1 s 一闪(柔和正弦)表示"活着",每帧只重绘冒号那一小块。
- 下方日期(12 px 大写字距 +2,y=172)与 `waiting for Mac`(12 px `#505050`,y=240)。

### IDLE

- 当前模式的点阵字形(dict = 麦克风、tr = 两个对话气泡、sub = CC 框),浅灰 `#C8C8C8`;每 4 s 一道扫描光自上而下掠过(800 ms),经过的点变白并略微放大。
- 模式名(`DICTATE` / `TRANSLATE` / `SUBTITLES`,20 px,y=220)。引擎名、分页点都去掉了,操作提示由右侧按键提示列显示。
- 切换模式:点阵从旧字形重排成新字形;模式名纵向翻牌(旧名字 140 ms 内向上 / 下翻出淡出,之后新名字从另一侧翻入,两行字不叠在一起)。
- 字幕在运行时(不论设备在哪个模式),Mac 发 `state sub`,设备显示 SUB 页;字幕应用选择器复用 LIST 页(标题 `CAPTIONS`)。

### REC

- 按下 OK:字形的点重排成一条线,中间那颗变成录音红;声波再从线上长出来(300 ms)。
- 点阵声波(`ib_ui_wave`,mirror):中央第 12 列是红色活柱,高度 = 当前音量(半高 0..7 颗,0.75 次方映射,每拍向目标靠近一半);每 100 ms 活柱存档成历史柱,历史柱整格跳向两侧并逐渐变暗(`#F0F0F0` → `#484848`)。静音时就是一条点线,配合状态栏红点与计时,安静但明显在录。节拍按时间推进(33 ms 一拍),掉帧时补齐,流动速度不变。
- 翻译听写模式只在下方加一个 12 px `translate` 图标(灰);没有其它文字,停止 / 取消由右侧提示列显示。

### PROC

- 声波按行塌缩成一条线,线变暗(`#303030`),一段约 5 颗点长的亮光在线上来回扫(单程 1.2 s)。没有文字。
- 上一句还在处理时**按键不可用**:右侧提示列整列画成禁用色(Mac 仍下发 OK 的麦克风图标),按下 OK 时不会开麦、不会开始新的一句,标记点闪红并左右抖动表示"不可用"(见「右侧按键提示列」)。Mac 端同时在处理中忽略 Passport 的 OK。

### DONE

- 只是一个状态,不是庆祝画面:线重排回当前模式的字形,点在飞行中变成完成绿,落地后 600 ms 内褪回 IDLE 的浅灰——约 1.2 s 后切回 IDLE 时画面已经一样,无缝衔接。
- 下方一行绿色状态字:`TYPED`,或 Mac 下发的 `msg`(如 `COPIED`;翻译 / 润色失败但已输入原文时为 `NOT TRANSLATED` / `NOT POLISHED`,由 `DeviceStateMapper.asciiResult` 给出),250 ms 起淡入并上移 6 px 到位。

### ERR

- 点重排成红色的叉,同时整体左右抖动 3 次(衰减);下方显示 `msg`(20 px,最多两行)。切回 IDLE 时叉再重排回模式字形。

### SUB

- 点先重排成一条白线,声波再从线上长出:点阵声波 scroll 排布,白色活柱在最右列,历史柱每 100 ms 向左跳一格、越远越暗(字幕是"听",不用录音红)。
- 下方显示应用名(`msg`,20 px,过长显示省略号);`STOP` / `TRANSLATE` / `HIDE` 等由右侧提示列显示。

## 右侧按键提示列

机身实体布局:电源键在左侧靠上;三个功能键在右侧,自上而下为 UP、DOWN、OK。提示贴着屏幕右边缘,与各自的实体键水平对齐(y ≈ 70 / 170 / 270):

```
          ┌──────────────────────┐
  电源 ▌  │USB              ●●●●●│
          │                  ↵ ⁚ │ ▐ UP    (y≈70)   图标 enter
          │   页面内容           │
          │   (左侧 218 px       │
          │    内居中)       ✕ ⁚ │ ▐ DOWN  (y≈170)  图标 esc
          │                      │
          │                  🎤⁚ │ ▐ OK    (y≈270)  图标 mic
          └──────────────────────┘
```

- 提示列宽 22 px(屏幕很小,提示只需要能认出来):每个键是一个 **12 px** 图标(Material Icons Round,Apache-2.0,中心 x=226),`#686868`,外加贴屏幕右边缘的 3 颗 2×2 竖排小点(间距 5,`#303030`),与界面的点阵语言一致。图标由 Mac 的 `keys` 命令按 id 选择(id 列表见 `protocol.md`);空字符串或未知 id 隐藏该键的提示。
- 图标字体由 `firmware/tools/gen-icon-font.sh` 从固定提交的上游字体生成(lv_font_conv,4 bpp):12 px 字体含 21 个按键提示字形(其中 ⌦ `del` 是把 backspace 水平镜像派生的字形;派生用临时 venv 里锁定版本的 fontTools,结果逐字节可复现),56 px 字体保留页面主图标字形表;两种字号来自同一张表,协议 id、固件枚举与字形一一对应。
- 按下某键:图标与 3 颗点 60 ms 冲到白,上下各多出一颗点,再用 240 ms 回落(共 300 ms),这是唯一的按键视觉反馈。
- **禁用**(PROC 页:上一句还在处理):整列画成更暗的禁用色;按下时改为"不可用"反馈——点 60 ms 内变红并左右抖动 3 次(360 ms),图标不亮起,让用户知道这次按键没有生效。
- 三个纵坐标(70 / 170 / 270)是固件 `ib_ui_hints.h` 里的常量 `IB_HINT_Y_UP/DOWN/OK`,实测偏差时只改这里。

## AGENT 通知层(vibe coding)

Mac 下发 `agent` 时,在任何页面上方弹出全屏通知层(录音中不打断录音,只在顶部显示 28 px 横幅,且不拦截按键;离开录音页后再转为全屏通知层)。横幅只占左侧内容区,内容为图标 + 来源名(如 `! Claude Code`),来源名过长时末尾显示省略号:
- 全屏通知的主体是大号点阵(节距 12、点 7 px):每颗点从屏幕外一圈沿自己的方向飞入拼成字形(按列错峰 8 ms,单颗 360 ms ease-out)。
- `done`:绿色点阵对勾,标题 `DONE`,下方来源名(如 `Claude Code`);15 s 自动关闭,所以不显示 `press any key`;提示音为上行三音。
- `input`:暗橙色(`#C88848`)点阵感叹号,整体亮度 2.4 s 周期呼吸,标题 `YOUR TURN`,下方 `press any key`;每 20 秒重复一次提示音,直到关闭。录音中的小横幅仍是圆形小图标(`!` 每 3 s 轻摇)+ 来源名。
- 出现时先用 100 ms 铺满黑色背景,再用 160 ms 淡入通知内容;关闭时先用 120 ms 淡出内容,再用 100 ms 撤掉背景。任何时刻通知内容都不会与下面的页面内容叠在一起。横幅整体 200 ms 淡入 / 淡出。
- 任意键关闭,或 Mac 发送 `clear`;`done` 15 秒后自动关闭。

## 按键反馈

- 任何按键:右侧对应的提示图标与标记点亮起 300 ms;禁用时(PROC)改为闪红抖动的"不可用"反馈(见上文);离线页没有提示列,不显示反馈。
- 去抖:ADC 层连续 4 次采样(20 ms)落在同一电压窗口才认定按下 / 松开;同一个键松开后 60 ms 内的再次按下视为触点回弹,整次忽略。一次实体按压只上报一次 `down` 与一次 `up`。
- 熄屏状态下,按键只负责点亮屏幕,不发送事件。
- 提示音(config `sound=1` 时):开始录音是上行双音(880→1320 Hz,各 40 ms),结束是下行双音,完成是短促一声,由设备本地合成并通过扬声器播放。
