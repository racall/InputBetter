# Passport 设备界面设计

屏幕 ST7789 240×320 竖屏,LVGL 9,只显示 ASCII(Montserrat 字体)。**不显示转录内容**,用动画表达状态。整体风格:克制的单色(参考 betterwispr / MemoEcho)——纯黑底,所有模式都用白 / 灰,光晕用极暗的精确灰,不用彩色和渐变;彩色只留给少数语义(录音红点、完成对勾、失败、Agent 等待输入),动画以柔和缓动为主。

## 配色

| 用途 | 颜色 |
| --- | --- |
| 背景 | `#000000` |
| 次要文字 | `#686868` |
| 主文字 / 图形 / 高亮(所有模式) | `#F0F0F0` |
| 细描边(IDLE 图标外圈) | `#505050` |
| 深灰面(列表行底、均衡器轨道、PROC 轨道) | `#181818` |
| 光晕 | `#080808`~`#303030` 的不透明精确灰 |
| 录音(只用于 REC 中心圆点与波纹、状态栏红点) | `#FF3B5C`(红) |
| 完成(只用于 DONE 圆环与对勾、Agent done 图标) | `#2EE59D`(绿) |
| 失败(只用于 ERR 的 X) | `#FF5A5A` |
| Agent 等待输入(只用于 input 通知) | `#C98B4F`(暗橙) |

模式之间不再用颜色区分,只靠图标、模式名与分页点区分。

**灰色必须是 RGB565 精确值**:R = G = B 且为 8 的倍数(屏幕是 16 位色,R/B 5 位、G 6 位,非精确灰会偏绿)。黑底上的"白色 + 低透明度"混合后同样会偏绿,所以光晕、底色一律画不透明的精确灰(固件 `ib_gray()`),不用透明度叠加。

## 布局

顶部 24 px 状态栏:左侧链路(`USB` / `BLE`),右侧电量(图形电池 + 百分比,充电时闪电)。其余区域按状态切换。页面切换用"先淡出、再淡入"(fade-through):旧页面 120 ms 淡出(ease-in)后隐藏,新页面再 180 ms 淡入并从下方 8 px 上移(ease-out),图标等再做轻微放大;两页任何时刻都不叠在一起。状态栏与按键提示立即切换。

在线页面的右侧 40 px 是按键提示列(见下文),页面内容只使用左侧 200 px,并在其中水平居中;离线时钟页和 Agent 全屏通知不显示提示列,使用整屏宽度。

### OFFLINE(Mac 未连接)
- 大字时钟(Montserrat 48)+ 日期,下面一行 `waiting for Mac`。
- 时钟下方一个缓慢呼吸(4 秒周期)的灰色小圆点。

### IDLE
- 中央是一个直径 96 px 的 2 px 灰色细圈(`#505050`),外面一圈极柔和的白色光晕(精确灰 `#080808`~`#303030`)以 3 秒周期呼吸;圈内没有底色。
- 圈内是 56 px 的 Material Icons Round 图标(与按键提示同一份上游字体,`gen-icon-font.sh` 生成):dict = `mic`、tr = `translate`、sub = `closed_caption`。
- 图标下方是模式名(`DICTATE` / `TRANSLATE` / `SUBTITLES`,Montserrat 20),再下面是 3 个分页点,当前模式的点为白色、略宽,其余为灰色。
- 图标与分页点下方是引擎名(小字);操作提示由右侧按键提示列显示。
- 字幕在运行时(不论设备在哪个模式),Mac 发 `state sub`,设备显示 SUB 页;听写 / 翻译模式下按键仍是听写的含义,提示图标由 `keys` 命令给出。字幕应用选择器复用 LIST 页(标题 `CAPTIONS`)。
- 切换模式时,图标和名字向左/右滑出、新的从另一侧滑入(250 ms ease-out),新旧卡片相距一整个内容区宽度(200 px),两个模式名不会重叠,超出内容区的部分被裁掉;细圈与光晕不动,分页点同步移动。

### REC
- 背景从中心渐亮出一层极淡的灰色径向光晕(两层不透明精确灰)。
- 中央是红色实心圆(直径约 56 px),外面 3 圈同心波纹环:按电平 `level` 放大,并持续向外扩散淡出(每 900 ms 发射一圈)。
- 圆周外是 32 根放射状电平条(圆形频谱,越长越亮,精确灰 → 白):长度由 level 加随机抖动驱动,平滑插值(每帧向目标值靠近 35%)。
- 顶部状态栏换成红点闪烁 + 计时 `00:07`。
- 底部一行 14 号灰色小字:按住 OK 时 `RELEASE OK`,免提模式 `OK TO STOP`(只是对右侧 OK 图标的补充);取消等提示由右侧按键提示列显示。
- 翻译听写模式下,中央圆仍为红色,外环带浅灰细描边,左上角(计时下方)显示 12 号灰色小字 `TRANSLATE`,不靠颜色也能区分。

### PROC
- 8 个小圆点沿圆周旋转,带拖尾(由白渐暗的精确灰),头部有一圈极淡的光晕。
- 中央文字 `THINKING`,文字透明度以 1.2 秒周期脉动。

### DONE
- 绿色圆环 300 ms 内画满,随后对勾描边动画,再加 12 个白色粒子向外迸散后淡出(绿色只用于圆环与对勾)。
- 下方显示 `TYPED`,或 Mac 下发的 `msg`(如 `COPIED`;翻译 / 润色失败但已输入原文时为 `NOT TRANSLATED` / `NOT POLISHED`,由 `DeviceStateMapper.asciiResult` 给出)。

### ERR
- 红色 X,左右抖动 3 次(每次 60 ms),下方显示 `msg`。

### SUB
- 顶部是灰框白字 `LIVE` 徽章 + 闪烁白点。
- 中部是一排 16 根竖向均衡器条(宽 8、间隔 4,水平居中,最高 120 px),由 level 驱动,各条带不同相位的正弦抖动、中间略高;条身为随高度变亮的精确灰(不用渐变),深灰轨道打底,条顶有缓慢下落的白色峰值帽。
- 均衡器下方显示应用名(`msg`,过长显示省略号);`STOP` 等操作提示由右侧按键提示列显示。

### LIST(Mac 驱动的列表,如应用切换器)
- 顶部标题(Mac 下发的 `title`,Montserrat 14 灰色,左对齐)。
- 最多 6 行圆角胶囊(高 34、间距 40):未选中为深灰底(`#181818`)白字,选中为白底黑字;`sel` 变化时白色高亮平滑滑到新行(每帧靠近 35%,约 150 ms),文字颜色在高亮覆盖过半时切换。项名过长时截断并加 `..`。
- 列表左侧一条 3 px 细滚动条:总项数 `n` 超过 6 时显示滑块,位置由 `top` / `n` 决定(右侧是按键提示列,所以放左边)。
- 设备不自行移动选中项,按键照常上报,由 Mac 更新后重发 `list`。

## 右侧按键提示列

机身实体布局:电源键在左侧靠上;三个功能键在右侧,自上而下为 UP、DOWN、OK。提示贴着屏幕右边缘,与各自的实体键水平对齐:

```
          ┌──────────────────────┐
  电源 ▌  │USB              87% │
          │                      │
          │               [↵] > │ ▐ UP    (y≈70)   图标 enter
          │   页面内容           │
          │   (左侧 200 px       │
          │    内居中)      [x] > │ ▐ DOWN  (y≈170)  图标 esc
          │                      │
          │                      │
          │              [mic] > │ ▐ OK    (y≈270)  图标 mic
          └──────────────────────┘
```

- 每个键是一个 22 px 图标(Material Icons Round,Apache-2.0),次要灰色 `#686868`(按下闪白时在精确灰之间过渡),后面一个指向机身边缘的小 `>`。图标由 Mac 的 `keys` 命令按 id 选择(id 列表见 `protocol.md`);空字符串或未知 id 隐藏该键的提示。
- 图标字体由 `firmware/tools/gen-icon-font.sh` 从固定提交的上游字体生成(lv_font_conv,4 bpp):22 px 字体含 21 个按键提示字形(其中 ⌦ `del` 是把 backspace 水平镜像派生的字形,Material 没有现成图标;派生用临时 venv 里锁定版本的 fontTools,结果逐字节可复现),56 px 字体含页面主图标(mic、translate、closed_caption、apps);两种字号来自同一张表,协议 id、固件枚举与字形一一对应。
- 按下某键时对应图标与箭头闪白 150 ms,这是唯一的按键视觉反馈(状态栏不再闪烁)。
- 三个纵坐标(70 / 170 / 270)是固件 `ib_ui_hints.h` 里的常量 `IB_HINT_Y_UP/DOWN/OK`,实测偏差时只改这里。
- IDLE 页原来的 `HOLD OK TO TALK` 提示由提示列承担。

## AGENT 通知层(vibe coding)

Mac 下发 `agent` 时,在任何页面上方弹出全屏通知层(录音中不打断录音,只在顶部显示 28 px 横幅,且不拦截按键;离开录音页后再转为全屏通知层)。横幅只占左侧内容区,内容为图标 + 来源名(如 `! Claude Code`),来源名过长时末尾显示省略号:
- `done`:绿色,中央对勾图标从小放大回弹,标题 `DONE`,下方来源名(如 `Claude Code`),背景两圈绿色细环向外扩散;提示音为上行三音。
- `input`:暗橙色(`#C98B4F`),中央 `!` 图标左右轻摇,标题 `YOUR TURN`,光环持续呼吸;每 20 秒重复一次提示音,直到关闭。
- 出现时先用 100 ms 铺满黑色背景,再用 160 ms 淡入通知内容;关闭时先用 120 ms 淡出内容,再用 100 ms 撤掉背景。任何时刻通知内容都不会与下面的页面内容叠在一起。横幅整体 200 ms 淡入 / 淡出。
- 任意键关闭,或 Mac 发送 `clear`;`done` 15 秒后自动关闭。

## 按键反馈

- 任何按键:右侧对应的提示图标闪白 150 ms(见上文);离线页没有提示列,不显示反馈。
- 去抖:ADC 层连续 4 次采样(20 ms)落在同一电压窗口才认定按下 / 松开;同一个键松开后 60 ms 内的再次按下视为触点回弹,整次忽略。一次实体按压只上报一次 `down` 与一次 `up`。
- 熄屏状态下,按键只负责点亮屏幕,不发送事件。
- 提示音(config `sound=1` 时):开始录音是上行双音(880→1320 Hz,各 40 ms),结束是下行双音,完成是短促一声,由设备本地合成并通过扬声器播放。
