# 2026-10-15 23:56 — macOS 端 Passport 设备通信层(USB / BLE / 协议 / ADPCM)

- 新增 `app/InputBetter/Device/`(每个文件只做一件事):
  - `DeviceTypes.swift`:对外值类型 `DeviceKey` / `DeviceKeyEvent` / `DeviceUIState` / `DeviceMode` / `DeviceConfig`,以及内部 `DeviceLinkKind`。
  - `DeviceLog.swift`:`DeviceLog.link`(subsystem `com.inputbetter.InputBetter`,category `device`)。
  - `SerialDeviceMonitor.swift`:IOKit 监听 VID 0x303A 的 `/dev/cu.*` 串口增删(主线程)。
  - `SerialPort.swift`:115200 raw、TIOCEXCL、关 HUPCL、先清 RTS 再清 DTR;内部串行队列读写,`writeAndClose` 供退出时同步发 `bye`。
  - `BLEClient.swift`:CoreBluetooth central,服务 `B5E10001-…`,Events / Commands / Audio In 特征;只在启用蓝牙时创建 CBCentralManager(不提前触发授权);Write Without Response 带排队流控。
  - `StreamDecoder.swift`:JSON 行 + `FF FE` 二进制帧解复用,帧可夹在行中间,第二字节 / 长度非法时重新同步。
  - `DeviceProtocol.swift`:`DeviceMessage.parse`(从 `{"t":` 起解析 hello / key / bat / pong)、`HostCommand` 编码(扁平 JSON,`cmd` 在前,手写转义)、`localClock`。
  - `DeviceText.swift`:屏幕文本转 ASCII(中文转拼音、去变音符号,其余为 `?`),截到 23 字节。
  - `RecentEventFilter.swift`:按 `(boot, seq)` 去重。
  - `IMAADPCMDecoder.swift`:164 字节块 → 320 个 16 kHz float 样本,低半字节在前。
  - `MicStream.swift`:`DeviceFrameSink` 协议 + 实现;后台串行队列解码麦克风帧,只接受当前链路的帧,统计丢帧。
  - `USBStreamPump.swift`:串口队列上解帧,音频直达 MicStream,协议消息切回主线程。
  - `DeviceLink.swift`:`@MainActor @Observable` 连接管理。USB 优先(USB 握手成功后断开 BLE,不发 bye);hello 最多 6 次 / 800 ms;每 5 秒 ping,16 秒无消息重连;握手后先重发缓存的 config / state / mic 再回调 `onConnectionChange`;config 每 5 分钟重发校准时钟;level 限流 50 ms。
- 新增 `app/InputBetterTests/DeviceProtocolTests.swift`:23 个用例,覆盖消息解析(含日志前缀、半行、垃圾行)、命令编码(转义、ASCII 截断、clock)、帧解复用(行中夹帧、逐字节输入、坏头重同步)、ADPCM(手算向量、nibble 顺序、正弦往返 SNR)、去重。
