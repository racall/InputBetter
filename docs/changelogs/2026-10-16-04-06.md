# 2026-10-16 04:06 — 字幕记录与保存、模型从接口获取、交互链路修复

- 字幕条的结束按钮由 ✕ 改为 ⏹「结束字幕」,菜单、设置里的文字统一为「结束字幕」。
- 字幕记录:
  - 新增 `CaptionTranscript`,保存一场字幕的全部句子(含译文和时间)。`SubtitleController.lines` 改为取记录的最后 3 句。
  - 新增字幕记录窗口(`UI/Transcript/TranscriptView`、`WindowManager.showTranscript`),可跟随最新、拷贝全部、保存。入口有三个:字幕条 📄、菜单「字幕记录…」、设置 › 实时字幕「查看」。
  - 结束字幕时询问是否保存(`TranscriptSaver`:NSAlert + NSSavePanel,用户选择保存位置,保存为 .txt)。
    - 提示框支持「不再询问」;设置里有对应开关 `askToSaveCaptions`。
    - 退出 app 时同样询问(`applicationShouldTerminate`)。
  - app 不保存任何字幕历史,记录只在内存里,下次开始字幕或退出后清除(按用户要求)。
  - 结束的所有入口统一走 `AppState.stopCaptions`。未定稿的半句会记入记录。
- 模型从接口获取:
  - 新增 `OpenAICompatibleAPI`,统一地址拼接、鉴权、错误解析和 `GET /models`。`LLMClient` 和 `OpenAITranscriptionDecoder` 改用它,去掉了重复实现。
  - 新增共用组件 `ModelPickerField`:下拉选择,带「手动输入…」和重新获取按钮。
  - LLM 配置:地址或 Key 改动后停顿 0.6 秒,自动拉取模型列表。
  - 云端识别:
    - OpenAI 兼容服务从接口拉取,并过滤出转写模型。
    - 火山引擎、百炼、ElevenLabs 没有公开的列表接口,改为列出官方文档里的模型 / 资源 ID 供选择,不再手动填写。
- 交互链路检查(由独立审查发现,逐条修复):
  - 上一次启动还没完成又开始字幕时,两场会同时运行且旧的停不掉。改为用 `generation` 丢弃过期的启动;音频采集失败时关闭已建立的云端连接。
  - 字幕启动失败时界面没有任何反馈。现在字幕条显示原因,并区分「未下载」和「未配置」,只保留 ✕ 关闭。
  - 设置里隐藏状态条后开字幕看不到字幕条。现在字幕期间强制显示,结束后恢复隐藏。
  - 选择正在转录的同一个应用会重开并清空记录。现在只展开字幕条。
  - 在保存面板打开期间新到的句子会被误标为已保存。改为只标记保存时那一刻的句数。
  - Passport 在未配置 AI 时能打开字幕翻译。改为与 Mac 上一致,需要先配置 AI。
  - 设备列表打开时 Mac 上开始听写,按键仍然归列表。现在开始听写时关闭列表。
  - 设备同步定时器改用 common 模式;询问框显示期间 Passport 不开 / 停字幕,也不会叠加询问框。
  - 听写中才开始的字幕会话没有暂停解码。现在进入 running 时立即按听写状态暂停。
  - 字幕模型不可用时选择框显示空白。现在显示「(不可用)」。
  - 云端配置新增「移除配置」;使用中的云端模型卡片也显示 ⚙。
- 测试:新增 `ModelListTests` 和 `CaptionTranscriptTests`(地址拼接、多种模型列表格式、错误信息、转写模型过滤、记录导出 / 保存状态 / 文件名)。共 91 个测试全部通过。
