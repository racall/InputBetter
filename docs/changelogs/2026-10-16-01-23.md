# 2026-10-16 01:23 — 固件更新入口、界面语言、快捷键简化、Codex 通知

## 改了什么
- **固件更新**:
  - 固件 hello 增加 `build`(ELF SHA256 前 8 位,由子 agent 修改固件)。
  - app 打包时从 `app.bin` 的 0xB0 处读出同一标识,写入 manifest。
  - 已连接时显示「固件 x · 有新固件 / 更新固件」,一致时显示「重新刷入」。
  - 刷写过程中显示进度卡片(新增 `PassportSetupModel.Stage.flashing`)。
  - `DeviceLink` 新增 `firmwareBuild`、`usbPortPath`。
- **界面语言**:
  - 中文 / English / 跟随系统(`AppLanguage`、`LanguagePicker`,在设置 › 通用和欢迎页),重启后生效。
  - 全部界面文字接入 String Catalog:`Localizable.xcstrings` 306 条,`InfoPlist.xcstrings` 是系统权限弹窗文字。
  - 英文按语境翻译,放在 `app/Localization/en.json`;新增 `scripts/update-strings.{sh,py}`。
  - 听写结果改为类型化(`DictationOutcome.swift`),Passport 状态映射不再比较中文文案。
- **快捷键简化**:
  - 去掉右⌥ / 右⌘ / fn 四选一和单修饰键监听(`ModifierKeyMonitor`、`TriggerKey` 已删除)。
  - 每个功能只有一个录制框,听写默认 ⌥空格;新增共用的 `ShortcutsCard`。
- **Vibe Coding**:
  - 只支持 Claude Code 与 Codex,各一键配置。
  - 实现为 `AgentHookInstaller`,两者共用一套 JSON 合并逻辑。
  - Codex 写入 `~/.codex/hooks.json`,不改动用户已有的 `notify`(本机已被 Codex Computer Use 使用)。
- **设置窗口**:默认 940×700,可调整大小并记住尺寸;侧边栏固定 236pt,英文不截断;所有选择框按内容宽度靠右对齐。
- **文档**:
  - `CLAUDE.md` 新增两条规则:每完成一个任务同步更新相关文档;界面文字规范。
  - 更新 `docs/architecture.md`:快捷键链、Agent hook 链、固件更新、界面语言链,以及公共能力表。
  - 更新 `README.md`、`docs/protocol.md`(由固件 agent 更新 hello 字段)。

## 为什么
按用户反馈:
- 已连接时没有更新固件的入口;
- 设置窗口要更大;
- 界面语言要支持中英文切换,英文要准确;
- 快捷键界面要简单;
- 选择框要右对齐;
- Vibe Coding 只需支持 Codex 和 Claude Code。
