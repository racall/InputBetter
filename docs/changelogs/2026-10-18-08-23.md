# 2026-10-18 08:23 — Passport:校时不再点亮屏幕、USB 在位 1 s 去抖、离线保留状态、充满判定;固件 0.1.3

- 现象(USB 连接、1 分钟熄屏):偶尔到点不熄屏、熄了又自己亮、偶尔闪出离线页、充电一直显示 94%。分析与方案见计划「Passport USB 连接时熄屏异常 / 偶发断开 / 充电卡 94%」。
- 固件 `firmware/main/ib_app.c`:
  - `IB_CMD_CONFIG` 不再 `wake()`。Mac 的 `DeviceLink.heartbeat()` 每 300 s 重发 config 校时,原来会让熄屏后的设备每 5 分钟自己亮一次,落在熄屏前几秒时还会重置计时、看起来"到点没熄"。`screen_off` 变化由 `refresh_backlight` 按新值立即生效(按 `s_last_activity_ms` 计算,无需额外处理)。点亮来源只剩按键、state、Agent 通知、链路恢复在线。
  - `refresh_links()` 改用去抖后的 USB 在位状态(`ib_links_usb_present`),不再读到一次 `usb_serial_jtag_is_connected()==false` 就清除 USB 链路、切离线页并亮屏。
  - `go_offline()` 不再把 `s_st` 重置为 idle、清空 `s_msg`:Mac 只在状态变化时发 state,离线抖动后设备会一直显示错误页面(例如字幕运行中却显示 IDLE)。现在只切 OFFLINE 页、停麦、清 Agent、复位按键,恢复在线时 `show_screen(screen_for(s_st))` 回到原页面;done / err 在离线时经新的 `revert_home()` 收拢到常驻页(离线期间不会再走自动返回,否则恢复后会卡在结果页);`s_revert_at` / `s_list_ready` 照旧清零。`refresh_timers` 的自动返回也改用 `revert_home()`,不重复实现。
  - `refresh_battery()` 改由 `ib_charge_update()` 推断显示 / 上报的电量与充电状态。
  - 文件头「时序要点」补充去抖、离线保留状态、点亮来源。
- 固件 `firmware/main/ib_links.{c,h}`:新增 `ib_links_usb_present()` 与 `IB_USB_ABSENT_CONFIRM_MS`(1000 ms)。插线立即在位;在位后要连续 1 s 读到不在位、且期间没收到 USB 命令才判拔线。ESP-IDF 的连接监测只是"约 4 ms 没收到 SOF 就判断开",Mac 睡眠 / 总线挂起会误报;1 s 取值依据是 Mac 拔线后本来就要 1 s(`usbRetryDelay`)才重开串口。
- 固件新增 `firmware/main/ib_charge.{c,h}`(纯逻辑):CW2017 是纯电压模型电量计、板上没有充电状态引脚,SOC 在恒压段饱和在 94% 到不了 100,原来 `chg = USB 在位 && soc < 100` 一直为真、无限播充电动画。现在 USB 在位、`soc ≥ 90`、`mv ≥ 4150` 持续 10 分钟视为已充满:`chg=0`,界面与 bat 消息的 soc 报 100;拔掉 USB、`mv < 4100`(50 mV 回差,避免充电 IC 终止后电压回落来回跳)或 `soc < 90` 即清除。阈值是经验值,待实测 `bat` 的 `mv` 后调整。bat 消息格式不变。`main/CMakeLists.txt`、`tools/validate.sh` 加入该模块与测试。
- 固件版本 `firmware/CMakeLists.txt` `PROJECT_VER` 0.1.2 → 0.1.3(`scripts/package-firmware.sh` 从编译产物读版本,无需其他改动)。
