# 2026-10-16 00:47 — macOS app 首版:听写、字幕、Passport、vibe coding

## 改了什么
- **app/**:XcodeGen 工程(macOS 26,Swift 6,依赖 WhisperKit 1.1.1 / sherpa-onnx 1.13.8 / KeyboardShortcuts 3.x),按职责分模块:
  - `Audio/`:16 kHz 音源协议;系统任意输入设备(`MicSource`);Passport 麦克风(`PassportMicSource`);按应用采集声音(`AppAudioTap`,Core Audio process tap,自动归并 Chrome / Safari 的 helper 进程)。
  - `ASR/`:`ASREngine` / `ASRSession` 协议。
    - `AppleSpeechEngine`:SpeechAnalyzer 原生流式。
    - `SenseVoiceEngine`、`WhisperEngine`:silero-vad 分段,整段重识别。
    - Whisper 在自动语言模式下先检测语言,只对中文加简体与标点提示词。
    - 预览结果已覆盖全部语音时直接复用,松开后几乎零等待。
    - `TranscriptText`:拼接、繁转简、半角转全角、去幻听。
  - `Models/`:模型目录与下载管理。
    - 推荐顺序:Whisper Turbo 压缩版(默认)→ SenseVoice → Apple Speech → Whisper Turbo → Whisper Small。
    - 下载完成写 `.installed` 标记;官方源与 hf-mirror 互为备用。
  - `Dictation/`:状态机;按住说话 / 短按免提(`PressInterpreter`);`TextInserter` 用剪贴板加 ⌘V 输入,完成后恢复剪贴板,安全输入或无权限时退化为复制。
  - `LLM/`:OpenAI 兼容客户端;润色、翻译听写、字幕翻译的提示词。
  - `Hotkey/`:单修饰键按住说话(右 ⌥ / 右 ⌘ / fn)与可录制的组合键。
  - `Pill/`:底部 Liquid Glass 胶囊状态条,形态包括空闲、悬停工具条、录音波形加实时文字、处理中、完成和失败。字幕条是胶囊的展开形态(不再是独立窗口),可拖动、记住位置、可锁定穿透。
  - `Subtitles/`:字幕数据。
  - `Vibe/`:Passport 按键动作(回车 / Esc / 撤销……)、Agent 通知(`inputbetter://agent` URL)、Claude Code hook 一键安装。
  - `Device/`:Passport 通信(子 agent 编写);新增运行其他固件的设备识别、刷固件时让出串口、最近按键状态。
  - `Device/Firmware/`:app 内一键刷固件(内置 esptool 5.6.0 独立版)。首次刷写先整片备份,只写 cardid 之前的区域。
  - `Bridge/DeviceBridge`:设备按键对应到听写、字幕和快捷键;app 状态同步到设备的 state、level、keys、config。
  - `Onboarding/`:7 步引导,依次为欢迎、权限、模型、快捷键、AI、Passport、试一试。Passport 一步包括检测设备、刷固件、按键测试、Passport 麦克风开关与测试、蓝牙。
  - `Settings/`:8 个分类,依次为通用、模型、快捷键、AI、字幕、Passport、Vibe Coding、词汇表。
  - `UI/`:设计规范与公共组件,以及 App 图标(`scripts/make-icon.swift`)。
  - `Debug/DebugHooks`:调试构建专用的自动化入口。
- **scripts**:`app/scripts/build.sh`、`test.sh`、`bundle-device-assets.sh`、`make-icon.swift`。
- **docs**:`protocol.md` 增加 keys / agent 命令与 ack;并入固件实现的偏差(录音中不拦截按键、chg 推断、按链路记录在线状态、麦克风时序);`device-ui.md` 增加按键栏与 Agent 通知层;新增 `README.md`。

## 为什么
- 实现需求:本地听写、应用声音实时字幕、Passport 硬件服务 vibe coding。
- 按反馈调整:界面要有设计;字幕条由胶囊变形而来;引导里加入 Passport 快速设置。
