**在线翻译**（子代理）
- **MT-1**：Google 的 Key 改放请求头 `X-goog-api-key`，不再出现在 URL 里。
- **MT-2**：超时按请求规模计算（10 + 字符数 / 500 秒，最多 30 秒）。原来统一 10 秒，批量翻译超时后重试会重复计费。
- **MT-3 百度**：
  - 条数对不上时按 `src` 回配拆行 / 吞行的结果，仍缺的那句才报错；
  - 句子之间的换行分隔符计入 6000 字节上限（`BatchLimits.separatorLength`）。

**听写 / 云端识别 / App 层**（子代理）
- **APP-1**：`flowTask` 每个 `await` 之后检查取消。处理中取消后不再粘贴，也不会变成「识别引擎未就绪」红字。
- **APP-2**：云端连接结束时 `finishTasksAndInvalidate`；重连前先关旧连接；旧连接迟到的消息按代号忽略。修复了每次重连泄漏一个 URLSession 的问题。
- **APP-3**：就绪超时会报告 `CloudASRError.timeout(服务名)`，「测试连接」因此能发现地址或资源 ID 配置错误。
- **APP-4**：转录中换应用时，上一场有未保存的记录就弹切换确认框，按钮是「切换 / 打开字幕记录 / 取消」，可以先打开记录去保存。原来上一场记录会被直接清掉，和确认框里的说法不符。

### 建议修改 / 可以优化（挑选必要的完成）

**界面**
- **UX-5**：「译」旁的 ⌄ 菜单在没开翻译时不勾任何语言。
- **UX-6**：字幕条标签显示「译 · 自动 → 简体中文」，悬停显示完整规则。
- **UX-7**：字幕条和字幕记录里的入口改为「实时字幕设置…」，打开 设置 › 实时字幕。
- **UX-8**：翻译中途出错时，在译文区下方常驻说明原因，翻译方式标签显示 ⚠。
- **UX-9**：「翻译不可用」带上具体原因，胶囊可点击打开 设置 › 听写。
- **UX-11**：翻译服务页的 AI 行不再显示默认模型名，改为说明模型在哪里选。
- **UX-12**：系统翻译语言包的行抽成 `SystemTranslationRows`，配置表单和引导页共用，并且会同时检查听写的目标语言。
- **UX-14**：字幕条的 小 / 大 按钮各自夹在范围内调整，一个到边界不影响另一个。
- **UX-15**：「边说边译」按方式写明代价：在线服务的额度约为整句翻译的 2–3 倍；系统翻译没有额外开销。
- **UX-17**：总结页未配置 AI 时显示「配置 AI 服务…」，配置后不再显示。

**翻译链路**
- **CODE-2**：`translateChunk` 先检查方式是否可用；记录窗口开跑前也检查。系统翻译语言包没装时停止整批，不再每块都失败。
- **CODE-4**：「译」菜单选语言时只翻译一次。实现方式：`SubtitleController` 记住上次翻译时的设置，设置监听再通知时发现没变就不重翻。
- **CODE-5**：AI 方式下，分句路径不再自己请求翻译。定稿时按文字把句子和记录关联起来，同一句只请求一次 AI。
- **CODE-6**：引擎给出空定稿时，用识别中已确认的文字顶替，不丢内容。
- **CODE-7**：`SentenceTranslator.reset` 取消排队中和已发出的请求，在线服务不再白白消耗额度；被取消的返回 `.cancelled`。
- **CODE-8**：系统翻译的语言包状态还在检查时不算可用；翻译前先查一次（`ensureSystemStatus`）。
- **CODE-11**：记录窗口的任务加了 `id`。取消后立刻再开新任务时，旧任务不会写入新任务的状态或错误。
- **CODE-12**：字幕条的定时器在对象释放后退出循环。
- **CODE-13**：用原文顶替之后整句译文才到的，再换成译文。
- **CODE-14**：「服务原样返回」记为不需要译文、目标是简体时统一转简体，这两步收到 `translateChunk` 里只做一次。
- **CODE-15**：模型菜单在拉取失败时显示原因。
- **CODE-16**：去掉冗余条件。

**在线翻译**（子代理）
- **MT-4**：补全火山、Azure、腾讯和 HTTP 408 / 425 的错误码归类。测试中发现一个真实 bug：腾讯的 `UnsupportedOperation.UnSupportedTargetLanguage` 大小写不一致，原来匹配不到，已修复。
- **MT-5**：限流时按 `Retry-After` 等待，最多 10 秒。
- **MT-8**：凭据文件创建时就是 0600 权限，目录 0700；值没变时不写盘。
- **MT-9**：凭据不全时抛 `.notConfigured`，不再发出注定失败的请求。
- **MT-10**：
  - RFC 3986 编码合并为 `SigningCrypto.rfc3986Encode`；
  - 长度改按 Unicode 码点计算；
  - 句内换行统一在 `TranslationService` 里替换；
  - 补充错误码测试；
  - 腾讯 TC3 签名按官方文档的中间值逐项对拍。

**听写 / 云端识别 / App 层**（子代理）
- **APP-5**：处理中按键不会吞掉下一次按键。
- **APP-6**：字幕模式下连续 3 次没能就绪，或握手返回 401 / 402 / 403 时，报告错误并停止重连。
- **APP-7**：去掉 `[unowned self]`，会话逻辑移到 `CloudStreamPump`。
- **APP-8**：模型列表只要求填了接口地址就拉取（第一次配置时就有列表可选）；`LLMConfigForm` 改用 `LLMModelCatalog`，删掉重复的拉取代码。
- **APP-9**：`TextInserter` 粘贴后立即返回，剪贴板异步恢复；连续多次输入时沿用同一份快照，不会把听写文本当成原剪贴板写回。
- **APP-11**：钥匙串迁移和清理旧 Key 只跑一次。
- **APP-12**：`AppSettings` 注入 `CredentialStore`，AppState 只创建一个实例，传给需要的地方。
- **APP-13**：引导完成只调用一次 `finishOnboarding`。
- **APP-14**：换字幕模型也会卸载旧引擎。

**文案**（子代理）
- L-9 到 L-18、L-23、L-24：统一「AI 服务」「接口地址」「刷新模型列表」等说法，改进多处英文表达，「AI 润色」按钮改为「润色译文」。

- **UX-10 字幕记录空状态加「开始字幕」按钮**：菜单栏、胶囊 ◉ 和快捷键已经能开始字幕；空窗口通常是用户主动打开来查看的，没有走不下去的问题。

- **UX-16 记录窗口「显示译文」做成眼睛按钮**：语言菜单里已有，属于偏好问题，没有改。
- **CODE-9 在线服务默认关闭边说边译**：只在文案里写明了额度消耗（UX-15）。默认值是否改动属于产品取舍，留给用户决定。

- **CODE-17 系统翻译批量接口**：收益很小。
- **CODE-19 / CODE-20 文案客观化、视图小重构**：纯优化。
- **CODE-21 `TranslatingBackend` 协议加假后端的整链测试**：工作量较大，留到下一轮。本轮已补上听写和云端会话层的整链测试。
- **MT-6 火山版本说明**：属于"需要核对"的条目，没有确认的问题。
- **MT-7 `RequestGate` 改等待队列**：当前的轮询实现功能正确，属于优化。
- **APP-10 辅助功能权限丢失时胶囊可点击**：涉及权限流程，留到下一轮。
- **APP-16 / APP-17 剩余的重复实现、死代码和测试盲点**：已在本轮顺带处理的除外，其余留到下一轮。
