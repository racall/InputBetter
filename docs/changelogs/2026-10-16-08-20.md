## Passport 链路(用户反馈转录时设备没有状态,随后按调用链全面检查)

- 设备在听写模式下转录字幕时只显示一个 LIVE 小标记。改为显示与按键分开:字幕在运行就显示字幕页(不论模式),按键含义仍按设备模式;提示图标随之对应。
- 审查发现并修复:
  1. 字幕模式下从 Mac 开始听写,设备 OK 键无效 → 听写进行中 OK 始终交给听写。
  2. 字幕页上按 OK 不会提前开 Passport 麦克风(丢首字)→ 固件在听写 / 翻译模式的 SUB 页也提前开麦,idle / sub 都有宽限期。
  3. Mac 上关掉 Agent 提醒不会清除设备 → `AgentNotifier.dismiss` 同步发 clear;设备重连后重发未处理的提醒。
  4. 按住说话时断线或 USB / 蓝牙切换会卡住 → 补发 pressUp;Passport 麦克风录音中断开时结束录音。
  5. 字幕模式下上键提示与行为不一致 → 没有字幕时轻按上键切换模式;翻译不可用时隐藏翻译提示。
  6. Passport 麦克风录音结尾被截掉 → 固件 rec → proc 继续推流,等 mic off,最多 500 ms。
  7. 设备上结束字幕会抢走焦点 → 只把字幕记录窗口放到前面,不激活 app。
  8. done / err 自动返回时闪出错误页面、Mac 与固件错误页时长不一致 → 固件回到「常驻页」(最近的 idle / sub 页面、模式、msg),Mac 错误页停留改为 2 秒;「NO APPS」改走正常状态同步。
  9. 设备列表可能触发 Mac 上无法回答的确认框 → Mac 正显示对话框或字幕已在运行时,只关闭列表。
- 固件删除已无用的空闲页 LIVE 标记逻辑;重新编译并刷入设备(整片备份已存在,未写 cardid)。
- 测试更新:字幕页规则、按模式的提示图标、翻译不可用时隐藏提示。
