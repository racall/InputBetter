# 2026-10-18 02:08 — 结束字幕的确认改成挂在 ⏹ 上的小气泡

- 改了什么
  - 新增 `app/InputBetter/UI/AnchoredPopover.swift`:把 `NSPopover` 包成 SwiftUI 修饰符 `anchoredPopover(isPresented:appearance:)`,
    可指定深色外观(SwiftUI 自带的 `.popover` 不能改外观);小三角由系统对准挂载的视图,点外面 / Esc 自动关闭。
  - 新增 `app/InputBetter/Pill/StopCaptionsBubble.swift`:`StopCaptionsPrompt`(待确认的询问:应用名、句数、本场 transcript.id、不再询问)
    和 `StopCaptionsBubble`(TipKit 风格的提示卡片:⏹ 图标 + 「结束字幕？」+ 说明 + 不再询问 / 取消 / 结束;「结束」自己画成强调色胶囊,
    因为气泡窗口不是 key 时系统的 borderedProminent 是灰的)。
  - `SubtitleSurface`:⏹ 按钮上挂 `anchoredPopover`,新增 `stopPrompt` Binding 与 `onConfirmStop`;
    `PillView` 把 `ui.stopPrompt` 作为 Binding 传入(置 nil = 取消),询问期间标题栏保持显示(否则气泡没有依托);
    `PillActions` 新增 `confirmStopCaptions` / `cancelStopCaptions`。
  - `PillUIState` 新增 `stopPrompt`;`PillPanelController` 新增 `showStopPrompt`(先显示状态条、展开字幕条)/ `dismissStopPrompt`。
  - `AppState.stopCaptions(from:)`:入口改成 `StopCaptionsSource`(`.surface` 字幕条 ⏹、`.command` 菜单 / 快捷键、`.device` Passport),
    替代原来的 `fromDevice:`;气泡已显示时 ⏹ 再点一次 = 取消、菜单 / 快捷键再触发一次 = 确认;
    新增 `confirmStopCaptions`(勾了「不再询问」就关设置,核对仍是同一场字幕)和 `finishCaptions`;`startCaptions` 先作废旧询问。
  - `CaptionsConfirmation` 删掉 `confirmStop`(NSAlert),只剩换应用 / 退出两个会丢记录的模态确认;`DeviceBridge` 注释同步。
  - `DebugHooks`:`IB_DEMO_CAPTIONS=1 IB_STOP_PROMPT=1` 启动后立即弹出气泡,便于检查排版。
  - 文档:`docs/architecture.md` 结束字幕调用链、`README.md` 功能描述、`CLAUDE.md` 调试变量。
- 为什么改
  - 结束字幕只是确认,原来居中的模态提示框太重、要把鼠标移到屏幕中间;用户要的是挂在结束按钮上、三角正对按钮的小气泡,顺手就能点。
- 验证情况
  - `update-strings.sh` 无缺失(文案沿用原有字符串);`test.sh` 186 个单元测试通过;
  - Debug 构建用 `IB_DEMO_CAPTIONS=1 IB_STOP_PROMPT=1` 真机截图确认:气泡在 ⏹ 正上方、三角对准按钮、深色外观;
    模拟点击「结束」后气泡关闭、字幕结束、字幕记录窗口打开。点外面关闭、Esc、Passport 上结束未在真机验证。
