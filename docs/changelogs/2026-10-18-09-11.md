# 2026-10-18 09:11 — 发布 0.1.7(固件 0.1.3):清理脚本、test.sh 门禁、复核与发布记录

- `scripts/clean.sh`(新增,用户要求"形成脚本,方便删除产物"):删除 app 与固件的全部编译 / 测试 / 打包产物(DerivedData、InputBetter.app、DMG、生成的 Xcode 工程、esptool、ESP-IDF 托管组件、sdkconfig、UI 预览产物、.DS_Store),每一项先用 `git check-ignore` 确认是忽略路径才删;`--keep-downloads` 保留需联网的 esptool 与托管组件,`--dry-run` 只列出。`CLAUDE.md`「常用命令」、`README.md` 登记。
- `app/scripts/test.sh`:干净目录里缺少 `DeviceAssets`(esptool)会导致链接失败,改为和 `build.sh` 一样先运行 `bundle-device-assets.sh`;原来退出码来自 grep、测试失败也返回 0,改为取 xcodebuild / swift test 自己的退出码,失败时非 0 退出(发版门禁)。
- 独立复核(Opus,只读)app ↔ Passport 交互链 8 个场景,结论可发布;发布前按复核修正两处(见 `2026-10-18-08-23.md` 末尾):在线→离线不再点亮屏幕(Mac 睡眠 SOF 停止导致的"熄了又亮"残留);"已充满"判定不再被 USB 短暂不在位或单次读数失败清掉,只由电压 / SOC 退出。
- 复核指出但本次未改的原有问题,留作后续:(1) 固件软件复位(panic / WDT)不会让 USB 重新枚举,Mac 不会重新握手,设备回到默认状态直到 Mac 下次变化;建议固件开机后在首条非 hello 命令上主动回 hello,Mac 对已握手链路上 boot 变化的 hello 按重新握手处理。(2) Mac 没察觉的离线(睡眠 / 唤醒)会丢掉设备上的 Agent 提醒和按住中的按键,不自愈;建议 Mac 监听 `NSWorkspace.didWakeNotification` 重同步。(3) 握手时补发的是断线时刻的旧 state,重连后可能多响一次提示音、闪一下旧页面。
