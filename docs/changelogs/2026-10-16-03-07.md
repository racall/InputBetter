# 2026-10-16 03:07 — 胶囊 / 字幕 / Passport 交互逻辑重构,签名配置与仓库解耦

## 改了什么
- **胶囊与字幕交互重新设计**:
  - 新增纯函数 `Pill/PillPresentation.swift`,决定胶囊形态和 ◉ 按钮含义(有单元测试)。
  - 点 ◉ 先弹出应用列表(正在播放的排在前面)再开始字幕,不沿用上一次;删除 `startLastApp` 和 `subtitleAppBundleID`。
  - 字幕条悬停时新增 🎤 听写,另有 ⌄ 收起、✕ 停止。
  - 收起后细胶囊带红点;悬停时 ◉ 是「展开字幕条」,停止在 ⌃ 菜单里。
  - 开关字幕快捷键在没有字幕时弹出应用列表。
  - 所有开始字幕的入口统一调用 `AppState.startCaptions`,设置页之前绕过了它。
  - 菜单栏和 ⌃ 菜单里可以收起 / 展开 / 停止字幕,解决字幕条锁定后点不到的问题。
- **听写优先**:字幕运行时可以听写。
  - 听写期间字幕暂停解码,音频照常缓存,结束后补上(`ASRSession.setDecodingPaused`、`SegmentedSession` 的 `PauseGate`)。
  - 胶囊在听写期间显示录音形态,结束后回到字幕条。
- **Passport 模式语义**:
  - 听写 / 翻译模式下 OK 始终是听写;字幕在后台运行时空闲页显示 LIVE(固件由子 agent 实现)。
  - 字幕模式下 OK 打开设备列表「CAPTIONS」选择应用,或停止字幕。
  - 字幕运行时也可以切换模式。
  - `DeviceBridge` 重写:列表页统一为 `ListSession`(切换应用 / 选择字幕应用)。
- **签名配置**:
  - `project.yml` 不再写死开发者身份,改用 `app/Config/Signing.xcconfig`(默认 ad-hoc)。
  - 本机身份写在 `Signing.local.xcconfig`(已加入 .gitignore),本机编译仍用固定证书,辅助功能授权不会失效。
- **文档**:`docs/architecture.md` 新增「3a. Passport 模式与 OK 键」和「6. 胶囊状态条与字幕交互」规则表;`docs/protocol.md` / `docs/device-ui.md` 由固件 agent 更新(LIVE)。
