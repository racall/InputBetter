# 2026-10-16 09:27 — Passport 按键动作新增 ⌫ 退格与 ⌦ Delete;固件 0.1.1

- 为什么改:用户希望说错时能直接在 Passport 上回退删除。
- app:
  - `Vibe/KeyAction.swift` 新增 `.backspace`(⌫ 退格,删除前一个字)和 `.forwardDelete`(⌦ Delete,删除后一个字),排在「⌘Z 撤销」之后,上键、下键、长按下键都可以选。
  - `Support/KeySender.swift` 发送 `kVK_Delete` / `kVK_ForwardDelete`,这两个是固定位置的功能键,与键盘布局无关。
  - `Device/DeviceTypes.swift` 的 `DeviceIcon` 新增 `bksp` / `del`;`UI/DeviceIconSymbol.swift` 用 SF Symbol `delete.left` / `delete.right`。
  - 英文翻译 2 条。
- 固件:
  - `tools/gen-icon-font.sh` 新增 `BKSP`(Material `backspace`)和 `DEL`。
  - Material 没有 ⌦ 图标,所以 `DEL` 是新增的「派生字形」:在临时 venv 里用锁定版本的 fontTools 4.60.1,把 backspace 水平镜像到私用区码点 U+F8FC,再交给 lv_font_conv。重新生成 `main/icons/` 下的字体和图标表,两次生成结果逐字节一致。
  - `tests/test_ib_protocol.c` 的固定 id 集合加上 `bksp` / `del`。
  - `tools/ui-preview` 新增 `idle_dict_delete_keys` 场景。
  - 版本 0.1.0 → 0.1.1。
- 兼容:旧固件收到 `bksp` / `del` 会隐藏该键的提示,按键动作本身照常执行(由 Mac 执行)。
- 测试:新增 `testIconIDsMatchFirmwareTable`,读取固件的 `ib_icon_list.h`,确认 app 与固件的图标 id 集合完全一致。
- 文档:`docs/protocol.md`(keys 的 id 集合)、`docs/device-ui.md`(图标字体)、`docs/architecture.md`(§4 调用链)、`README.md`。
- 验证:
  - app 单元测试 119 个通过;固件主机测试通过;`update-strings.sh` 无缺失。
  - 界面预览确认上键显示 ⌫(朝左)、下键显示 ⌦(朝右)。
  - 真机:已有整片备份,用 `flash-firmware.sh` 刷入 0.1.1,握手正常(hello ver=0.1.1)。没有改用户的按键设置,所以设备上的 ⌫ / ⌦ 提示和实际删除效果需要用户在设置里选上后确认。
  - 单次按下删除一个字符;按住不会连续删除,因为长按已经分配给切换模式 / 自定义动作。整段删除可以用 ⌘Z。
