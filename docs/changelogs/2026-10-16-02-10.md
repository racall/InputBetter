# 2026-10-16 02:10 — 语言即时切换、Passport 按键布局与切换应用、呼吸胶囊

## 改了什么
- **界面语言即时切换,不再需要重启**:
  - 新增 `Support/Localization.swift`(`L10n` 当前语言资源包、`LanguageState`)。
  - 所有 `String(localized:)` 改为从 `Bundle.l10n` 取。
  - 根视图用 `LocalizedRoot` 注入 locale,并在切换时重建。
  - `ModelCatalog.all` 改为每次访问生成;切换时同步窗口标题。
  - 删除重启按钮与 `AppLanguage.relaunch`。
- **Passport 麦克风说明改清楚**:OK 键始终可以听写,开关只决定用 Mac 还是设备的麦克风收音;通用页说明同步修改。
- **按真实按键布局**:左上侧是电源键,右侧从上到下是上键、下键、OK 键。
  - `PassportIllustration` 重画:右侧竖排侧键,屏幕右边的提示紧贴对应按键,按真机按键时侧键高亮。
  - 按键说明按实体键顺序排列,并显示当前的按键映射。
  - 固件改为右侧竖排提示列,删除底部按键栏(子 agent 完成)。
  - 所有按键提示缩短到 7 个字符以内(TALK、CANCEL、TR OFF、CMD+RET……),并加了测试确保不超出。
- **Passport 切换应用**:
  - 新增动作 `KeyAction.appSwitcher`,作为长按下键的默认动作。
  - 列出 Mac 上打开的应用,按最近使用排序(`AppSwitcher`)。
  - 设备显示列表页(新协议命令 `list`、状态 `st:"list"`,固件由子 agent 实现),▲▼ 选择,OK 前置并聚焦,长按 ▼ 或 15 秒无操作关闭。
  - 前置行为按 ⌘Tab / Dock 的通行做法:取消隐藏、AX 设为最前、抬起或恢复最小化窗口、没有窗口时让应用重新打开。
- **空闲胶囊呼吸**:
  - `IdleCapsule` 缓慢呼吸,尊重"减少动态效果"。
  - 30 秒无活动后变淡但仍可见,有活动立即恢复。
  - 玻璃由容器统一渲染,外层 opacity 不生效,所以改成内芯降亮度、玻璃换成 clear 样式。
- **规则**:`CLAUDE.md` 新增"符合业内通用做法,不为省事省略必要环节"。
- **文档**:`docs/architecture.md` 更新语言链、切换应用链、胶囊变淡说明和公共能力表;`README.md` 更新 Passport 键位与语言说明;`docs/protocol.md` / `docs/device-ui.md` 由固件 agent 更新(list 命令、右侧提示列)。
